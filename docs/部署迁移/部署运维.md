# InkWeaver 运维与部署

**文档版本**：2.1  
**最后更新**：2026-06-12

---

## 1. 目标架构

```
用户浏览器
    ├── Nginx ──► /opt/inkweaver/web（apps/web dist）
    └── 同源或子域反代
            ├── /api ──► Nest :3000
            ├── /sync、/socket.io ──► WebSocket
            └── /uploads ──► 本地卷或后续 OSS

Nest Server（Docker）
    ├── PostgreSQL
    ├── Redis（BullMQ）
    ├── MinIO（可选，通用对象存储）
    └── SMTP
```

## 2. 环境变量

环境文件**不纳入 Git**（`.gitignore`）。本地需自备根目录 `.env`、`apps/server/.env`；生产需自备根目录 `.env.prod`。

### 2.1 必须保持一致的变量

| Docker Compose | Nest Server | 说明 |
|----------------|-------------|------|
| `POSTGRES_PASSWORD` | `DB_PASSWORD` | 同一强密码 |
| `REDIS_PASSWORD` | `REDIS_PASSWORD` | 同一强密码 |

### 2.2 本地开发（根 `.env` + `apps/server/.env`）

两处文件内容应对齐。根 `.env` 供 `docker compose`；`apps/server/.env` 供 Nest 与 TypeORM CLI。

| 变量 | 典型值 | 说明 |
|------|--------|------|
| `POSTGRES_PASSWORD` | 强密码 | Docker postgres |
| `REDIS_PASSWORD` | 强密码 | Docker redis |
| `PORT` | `3000` | Nest 端口 |
| `NODE_ENV` | `development` | |
| `DB_HOST` | `localhost` | |
| `DB_PORT` | `5432` | |
| `DB_USERNAME` | `postgres` | |
| `DB_PASSWORD` | 与 `POSTGRES_PASSWORD` 相同 | |
| `DB_DATABASE` | `syncbox_db` | |
| `REDIS_HOST` | `localhost` | |
| `REDIS_PORT` | `6379` | |
| `REDIS_PASSWORD` | 与 Docker 相同 | |
| `JWT_SECRET` | 随机字符串 | 仅开发 |
| `JWT_EXPIRES_IN` | `7d` | |
| `APP_PUBLIC_URL` | `http://localhost:3003` | 邮件链接等 |
| `SMTP_HOST` | `localhost` | Mailhog |
| `SMTP_PORT` | `1025` | |
| `SMTP_SECURE` | `false` | |
| `SMTP_FROM` | `InkWeaver <noreply@localhost>` | |
| `TYPEORM_ENABLED` | 可选 `false` | 无 DB 时显式关闭 |

### 2.3 生产（根 `.env.prod`）

`docker-compose.prod.yml` 与 server 容器共用此文件。

| 变量 | 说明 |
|------|------|
| `POSTGRES_PASSWORD` / `DB_PASSWORD` | 强密码，必须一致 |
| `REDIS_PASSWORD` | 强密码 |
| `UPLOADS_HOST_PATH` | 默认 `/opt/inkweaver/uploads` |
| `MINIO_ROOT_USER` / `MINIO_ROOT_PASSWORD` | MinIO 控制台与 S3 |
| `DB_HOST` | `postgres`（compose 服务名） |
| `REDIS_HOST` | `redis` |
| `NODE_ENV` | `production` |
| `APP_PUBLIC_URL` | 如 `https://app.example.com` |
| `CORS_ORIGIN` | 逗号分隔允许源 |
| `SMTP_*` | 生产 SMTP；`SMTP_PASS` 建议仅 shell `export`，勿写入 Git |
| `SKIP_MIGRATIONS` | 可选 `true` 跳过容器启动迁移 |

### 2.4 Web 构建变量（`apps/web`）

| 变量 | 开发 | 生产（单域 Nginx） |
|------|------|-------------------|
| `VITE_APP_PUBLIC_URL` | `http://localhost:3003` | `https://你的域名` |
| `VITE_API_BASE_URL` | 可留空（Vite 代理） | 通常留空，走同源 `/api` |
| `VITE_SYNC_SOCKET_URL` | 可留空 | 可留空，走同源 `/sync` |

### 2.5 实例信息（域名、ECS IP、SSH 密钥路径）

勿写入 Git。复制 [`deploy/INSTANCE.local.example`](../../deploy/INSTANCE.local.example) 为 `deploy/INSTANCE.local.md`（已 gitignore）。

### 2.6 Web 构建与同步

```bash
bash deploy/scripts/build-web-local.sh https://app.example.com
bash deploy/scripts/deploy-web.sh root@ECS_IP
```

## 3. 本地开发

```bash
pnpm install
# 自备根 .env 与 apps/server/.env（见 §2.2）
docker compose up -d
pnpm dev:server
pnpm dev:web
```

Mailhog：http://localhost:8025

## 4. 生产单机 Docker（2C2G+）

### 4.1 交付物

| 文件 | 说明 |
|------|------|
| [`docker-compose.prod.yml`](../../docker-compose.prod.yml) | PG + Redis + MinIO + Server |
| [`apps/server/Dockerfile`](../../apps/server/Dockerfile) | 多阶段构建；`pnpm deploy --legacy` |
| [`deploy/nginx/inkweaver.cn.conf`](../../deploy/nginx/inkweaver.cn.conf) | 单域 + storage/s3 子域（**推荐**） |
| [`deploy/nginx/inkweaver.conf`](../../deploy/nginx/inkweaver.conf) | 单域模板（占位域名） |
| [`deploy/scripts/`](../../deploy/scripts/) | provision、deploy-web、备份 |

### 4.2 部署脚本索引

| 脚本 | 执行位置 | 用途 |
|------|----------|------|
| `ecs-init.sh` | ECS root | Docker、swap、ufw、目录 |
| `provision-inkweaver-cn.sh` | ECS root | **推荐**：全栈 bootstrap（git、`.env.prod`、compose、nginx.cn） |
| `bootstrap-on-server.sh` | ECS root | 与 provision 功能重叠，优先用 provision |
| `deploy-backend.sh` | ECS `/opt/inkweaver/repo` | compose up + `readyz` |
| `build-web-local.sh` | 开发机 | `VITE_APP_PUBLIC_URL` + `pnpm build:web` |
| `deploy-web.sh` | 开发机 | rsync → `/opt/inkweaver/web/` |
| `setup-nginx-ssl.sh` | ECS | `inkweaver.conf` + certbot |
| `backup.sh` | ECS cron | pg_dump + uploads tar |

### 4.3 内存与构建

- 增加 **2GB swap**（`deploy/scripts/ecs-init.sh`）
- **勿在 ECS 上 `pnpm build` Web**；本地构建后 `deploy-web.sh` 同步

### 4.4 上线命令

```bash
sudo bash deploy/scripts/ecs-init.sh

cd /opt/inkweaver/repo
# 编辑根 .env.prod（见 §2.3）
export SMTP_PASS='授权码'   # 仅 shell export，勿写入 Git
docker compose -f docker-compose.prod.yml --env-file .env.prod up -d --build

bash deploy/scripts/build-web-local.sh https://app.example.com
bash deploy/scripts/deploy-web.sh root@ECS_IP

sudo certbot --nginx -d app.example.com -d www.app.example.com \
  -d storage.app.example.com -d s3.app.example.com
```

或使用：`sudo -E DOMAIN=app.example.com bash deploy/scripts/provision-inkweaver-cn.sh`

### 4.5 DNS（单域 + MinIO 子域示例）

| 主机记录 | 类型 | 值 |
|----------|------|-----|
| `@` / `www` | A | ECS 公网 IP |
| `storage` | A | 同上（MinIO 控制台） |
| `s3` | A | 同上（S3 API） |

### 4.6 MinIO

| 用途 | 路径 |
|------|------|
| Web 控制台 | `https://storage.你的域名` |
| S3 API | `https://s3.你的域名` |
| 默认桶 | `inkweaver` |

账号见 `.env.prod` 中 `MINIO_ROOT_*`。应用内头像/图片仍走 `/opt/inkweaver/uploads`（`/uploads/...`）。

### 4.7 静态资源权限

`scp` 上传后若白屏且控制台 MIME 为 `text/html`：

```bash
find /opt/inkweaver/web -type d -exec chmod 755 {} \;
find /opt/inkweaver/web -type f -exec chmod 644 {} \;
```

`deploy-web.sh` 已包含远程 chmod。Nginx 对 `/assets/` 使用 `try_files $uri =404` 避免误回退 HTML。

### 4.8 备份

```cron
0 3 * * * /opt/inkweaver/repo/deploy/scripts/backup.sh >> /var/log/inkweaver-backup.log 2>&1
```

## 5. 数据库迁移

| 环境 | 命令 |
|------|------|
| 开发 CLI | `pnpm --filter @inkweaver/server migration:run` |
| 生产容器 | `docker-entrypoint.sh` 自动执行 `run-migrations.js`（`SKIP_MIGRATIONS=true` 可跳过） |

迁移文件：[`apps/server/src/migrations/`](../../apps/server/src/migrations/)。开发环境 `synchronize: true` 时可不跑 migration；生产必须依赖 migration。
